# 결측값 처리

> [!summary] 한눈에 보기
> 결측값 처리는 비어 있거나 유효하지 않은 값을 탐지하고 분석 목적에 맞게 제거, 대체, 모델링하는 과정이다. 단순히 `NaN`을 없애는 작업이 아니라 결측이 발생한 이유와 결과에 미치는 영향을 판단해야 한다.

## 왜 배우는가

결측값을 무시하면 요약통계, 시각화, 회귀계수와 모델 성능이 왜곡될 수 있다. 반대로 근거 없이 행을 제거하거나 평균으로 대체하면 중요한 정보가 사라지고 불확실성이 과소평가될 수 있다.

## 결측값 표현

CSV 파일에서는 다음 값이 모두 결측을 의미할 수 있다.

- 빈 문자열
- `NA`, `N/A`, `null`
- `-`, `없음`, `미응답`
- 특정 숫자 코드인 `-999`

문제는 `-`나 `없음`처럼 pandas가 자동으로 결측값으로 인식하지 않을 수 있는 표현이다. 데이터 사전과 원자료를 확인해 어떤 값이 실제 결측인지 결정한다.

## 오류가 발생하는 이유

숫자 열에 문자열이 섞이면 열 전체가 문자열 또는 `object` dtype으로 읽힐 수 있다. 이 상태에서 평균을 계산하면 숫자 연산이 실패하거나 예상하지 못한 결과가 발생할 수 있다.

## 재현 가능한 예제

```python
from io import StringIO

import pandas as pd

csv_text = """student_id,score
1,85
2,-
3,없음
4,92
5,
"""

data = pd.read_csv(StringIO(csv_text))

print(data)
print(data["score"].dtype)
```

`score` 열에 숫자와 문자열이 함께 있어 숫자형으로 사용하기 어렵다.

## 읽을 때 결측값 지정

`read_csv`의 `na_values`에 데이터 고유의 결측 표현을 전달한다.

```python
from io import StringIO

import pandas as pd

csv_text = """student_id,score
1,85
2,-
3,없음
4,92
5,
"""

data = pd.read_csv(
    StringIO(csv_text),
    na_values=["", "-", "없음"],
)
data["score"] = pd.to_numeric(
    data["score"],
    errors="coerce",
)

print(data)
print(data["score"].dtype)
print(data["score"].isna().sum())
print(data["score"].mean())
```

`errors="coerce"`는 숫자로 변환할 수 없는 값을 결측값으로 바꾼다. 편리하지만 예상하지 못한 값까지 결측으로 바뀔 수 있으므로 변환 전후 결측값 개수와 원래 문자열을 반드시 확인한다.

## 변환 과정 점검

```python
original_score = data["score"].copy()
converted_score = pd.to_numeric(
    original_score,
    errors="coerce",
)

new_missing_mask = converted_score.isna() & original_score.notna()
unexpected_values = original_score[new_missing_mask]

print(unexpected_values)
```

실제 분석에서는 변환 전에 원본 열을 별도로 보존해야 한다. 이미 `read_csv`에서 결측 처리가 끝났다면 원본 문자열을 확인할 수 있도록 원본 데이터 파일을 수정하지 않고 유지한다.

## 결측 현황 확인

```python
missing_count = data.isna().sum()
missing_rate = data.isna().mean().mul(100)

missing_summary = pd.DataFrame({
    "missing_count": missing_count,
    "missing_rate_percent": missing_rate,
})

print(missing_summary)
```

전체 개수뿐 아니라 변수별 결측 비율, 특정 집단에서의 집중 여부, 여러 변수의 동시 결측 패턴을 확인한다.

## 처리 방법

### 행 또는 열 제거

```python
complete_rows = data.dropna(subset=["score"])
```

결측 비율이 작고 결측 발생이 분석 결과와 체계적으로 관련되지 않을 때 검토할 수 있다. 무조건 삭제하면 표본 크기와 대표성이 감소한다.

### 단순 대체

```python
median_score = data["score"].median()
data["score_imputed"] = data["score"].fillna(median_score)
```

중앙값 대체는 이상치에 비교적 덜 민감하지만 분산과 변수 간 관계를 왜곡할 수 있다. 학습용 기준선으로는 사용할 수 있어도 한계를 기록해야 한다.

### 집단별 대체

전공, 학년, 측정 시점처럼 합리적인 집단 구조가 있으면 집단별 대표값을 검토할 수 있다. 결과변수나 테스트 데이터 정보를 사용하면 [[데이터 누수]]가 생길 수 있다.

### 모델 기반 방법

다중대치나 예측모형 기반 대체는 변수 관계와 대치 불확실성을 더 잘 반영할 수 있지만 가정과 구현이 복잡하다. 분석 목적과 결측 메커니즘을 고려해야 한다.

## 머신러닝 파이프라인 주의

대체 기준은 훈련 데이터에서만 학습하고 검증·테스트 데이터에는 같은 값을 적용한다.

`전체 데이터 중앙값 계산 → 데이터 분할` 순서는 테스트 데이터 정보가 훈련 과정에 들어가는 데이터 누수가 될 수 있다.

## 자주 하는 실수

- 빈칸만 결측값이라고 생각한다.
- `errors="coerce"` 후 새로 생긴 결측값을 확인하지 않는다.
- 원본 데이터를 직접 덮어쓴다.
- 결측값이 많은 행을 근거 없이 삭제한다.
- 평균 대체 후 분산과 상관관계가 유지된다고 생각한다.
- 전체 데이터로 대체값을 계산한 뒤 훈련·테스트 데이터를 나눈다.
