# 15. 이차형식

> [!summary] 한눈에 보기
> 이차형식은 $x^TAx$ 형태의 스칼라 함수다. 곡면의 모양, 최적화 문제의 곡률, 분산과 거리 구조를 설명한다.

## 정의

$A$가 $n\times n$ 행렬이고 $x\in\mathbb{R}^n$이면

$$
q(x)=x^TAx
$$

를 이차형식이라 한다.

## $2\times2$ 전개

$$
A=\begin{bmatrix}a&b\\b&d\end{bmatrix},\qquad
x=\begin{bmatrix}x_1\\x_2\end{bmatrix}
$$

이면

$$
x^TAx=ax_1^2+2bx_1x_2+dx_2^2
$$

이차형식에서는 $A$의 대칭부분만 결과에 영향을 주므로 대칭행렬을 주로 사용한다.

## 정부호성

- **양의 정부호:** 모든 $x\ne0$에 대해 $x^TAx>0$
- **양의 준정부호:** 모든 $x$에 대해 $x^TAx\ge0$
- **음의 정부호:** 모든 $x\ne0$에 대해 $x^TAx<0$
- **부정부호:** 양수와 음수 값을 모두 가짐

대칭행렬이 양의 정부호일 필요충분조건은 모든 고유값이 양수인 것이다.

## 예제

$$
A=\begin{bmatrix}2&0\\0&1\end{bmatrix}
$$

$$
x^TAx=2x_1^2+x_2^2
$$

$x\ne0$이면 항상 양수이므로 $A$는 양의 정부호다.

## 데이터 분석 연결

평균벡터 $\mu$와 공분산행렬 $\Sigma$를 사용하는 [[마할라노비스 거리]]는 다음 이차형식을 이용한다.

$$
d^2(x,\mu)=(x-\mu)^T\Sigma^{-1}(x-\mu)
$$

최적화에서는 헤시안의 정부호성이 국소최솟값 판단과 연결된다.

## Python으로 확인

```python
import numpy as np

matrix = np.array([[2.0, 0.0], [0.0, 1.0]])
vector = np.array([3.0, 4.0])

quadratic_value = vector.T @ matrix @ vector
eigenvalues = np.linalg.eigvalsh(matrix)

print(quadratic_value)
print(eigenvalues)
```

## 자주 하는 실수

- $x^TAx$의 결과를 벡터로 생각한다.
- 대칭행렬의 고유값과 정부호성 연결을 놓친다.
- 양의 준정부호와 양의 정부호를 구분하지 않는다.
