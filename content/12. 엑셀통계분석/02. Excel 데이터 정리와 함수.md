# 02. Excel 데이터 정리와 함수

> [!summary] 한눈에 보기
> Excel 통계 분석의 출발점은 한 행을 하나의 관측치, 한 열을 하나의 변수로 정리하는 것이다. 셀 참조, 자료형, 결측값과 중복을 먼저 점검해야 함수와 분석 도구의 결과를 신뢰할 수 있다.

## 권장 데이터 구조

| student_id | group | score | study_hours |
|---|---|---:|---:|
| 1 | A | 80 | 3.5 |
| 2 | B | 92 | 5.0 |

- 첫 행에는 고유한 변수명을 둔다.
- 한 셀에는 하나의 값만 저장한다.
- 병합 셀과 중간 합계 행을 원자료 안에 넣지 않는다.
- 숫자에 `점`, `원`, `%` 같은 문자를 직접 붙이지 않는다.

## 상대참조와 절대참조

`B2*C2`는 수식을 아래로 복사하면 행 번호가 바뀌는 상대참조다.

```text
=B2*C2
```

세율이 `F1`에 고정되어 있다면 절대참조를 사용한다.

```text
=B2*(1+$F$1)
```

## 자주 사용하는 함수

| 목적 | 함수 예 |
|---|---|
| 관측치 수 | `=COUNT(C2:C101)` |
| 비어 있지 않은 셀 수 | `=COUNTA(A2:A101)` |
| 조건별 개수 | `=COUNTIF(B2:B101,"A")` |
| 조건별 평균 | `=AVERAGEIF(B2:B101,"A",C2:C101)` |
| 결측 여부 | `=ISBLANK(C2)` |
| 오류 처리 | `=IFERROR(A2/B2,"")` |

## 데이터 점검

- 숫자가 텍스트로 저장되지 않았는가?
- 날짜가 실제 날짜 형식인가?
- 같은 식별자가 중복되지 않았는가?
- 결측값을 $0$으로 입력하지 않았는가?
- 범주 이름의 공백과 철자가 일관적인가?

## 자주 하는 실수

- 화면을 보기 좋게 만들기 위해 원자료 셀을 병합한다.
- 빈 셀과 실제 $0$을 같은 의미로 사용한다.
- 필터링된 행만 분석했다고 생각하지만 숨은 행까지 함수에 포함한다.
- 수식 셀을 값으로 붙여넣지 않고 원자료를 덮어쓴다.
