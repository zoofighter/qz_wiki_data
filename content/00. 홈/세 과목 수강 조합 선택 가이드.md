# 세 과목 수강 조합 선택 가이드

> [!summary] 결론
> 특별한 선수 지식이 없다면 [[00. 엑셀통계분석 목차]]와 [[00. 파이썬데이터분석 목차]]의 조합이 가장 균형이 좋다. 이미 통계나 Python을 알고 있거나 금융 분야가 명확한 목표라면 [[스마트금융데이터분석 목차]]를 포함한 조합이 더 효율적이다.

## 세 과목의 역할

- [[00. 엑셀통계분석 목차]]: 통계 원리와 결과 해석
- [[00. 파이썬데이터분석 목차]]: 코딩과 데이터 처리
- [[스마트금융데이터분석 목차]]: 금융 분야의 머신러닝·시계열 응용

## 한눈에 비교

| 과목 | 주요 학습 내용 | 강점 | 주의점 |
|---|---|---|---|
| [[00. 엑셀통계분석 목차]] | 기술통계, 확률분포, 추정, 검정, 회귀 | 통계 기초와 결과 해석 | 프로그래밍 역량은 거의 늘지 않음 |
| [[00. 파이썬데이터분석 목차]] | Python 문법, pandas, 수집, 시각화, 머신러닝 | 활용 범위가 넓은 분석 기반 | 한 학기에 다루는 범위가 넓음 |
| [[스마트금융데이터분석 목차]] | 금융 데이터, 머신러닝, 텍스트, 시계열 | 금융 분야의 실전 응용 | 통계와 Python 기초가 부족하면 어려움 |

## 기본 추천

> [!tip] 가장 무난한 선택
> **[[00. 엑셀통계분석 목차]] + [[00. 파이썬데이터분석 목차]]**

통계학과 프로그래밍을 함께 배울 수 있어 가장 균형이 좋다. [[00. 엑셀통계분석 목차]]에서 [[01. 모집단과 표본]], [[03. 기술통계량]], [[가설검정]], [[회귀분석]]의 의미를 배우고, [[00. 파이썬데이터분석 목차]]에서 같은 분석을 코드로 구현할 수 있다.

특히 다음 학기에 [[스마트금융데이터분석 목차]], [[머신러닝 목차]], [[딥러닝 목차]]를 공부할 계획이라면 가장 안정적인 조합이다.

## 사례 1: 통계와 코딩을 모두 처음 배우는 경우

### 추천 조합

**[[00. 엑셀통계분석 목차]] + [[00. 파이썬데이터분석 목차]]**

### 이유

- 통계 용어와 결과 해석을 배울 수 있다.
- Python 문법과 데이터 처리 방법을 배울 수 있다.
- 겹치는 내용을 Excel과 Python으로 반복 학습할 수 있다.
- 이후 금융 데이터와 머신러닝 과목을 위한 기초가 된다.

### 예상 학습 흐름

```text
Excel로 평균과 표준편차 계산
→ 통계적 의미 이해
→ Python으로 같은 계산 구현
→ 실제 데이터에 반복 적용
```

[[스마트금융데이터분석 목차]]는 다음 학기로 미루는 것이 좋다. Python과 통계 기초가 부족하면 금융 응용보다 문법과 공식에 대부분의 시간을 사용할 수 있다.

## 사례 2: 통계는 알지만 Python이 처음인 경우

### 추천 조합

**[[00. 파이썬데이터분석 목차]] + [[스마트금융데이터분석 목차]]**

이미 평균, 분산, 확률분포, 가설검정, 회귀분석을 이해한다면 Excel 과목의 상당 부분이 복습이 될 수 있다. Python과 pandas를 배운 뒤 금융 데이터에 바로 적용할 수 있다.

### 기대되는 연결

- [[02. Python 변수와 자료형]] → 금융 변수 처리
- [[pandas DataFrame]] → 주가·재무 데이터 정리
- [[Python 회귀분석 실습]] → 금융 수익률 분석
- [[머신러닝 모델 평가]] → 금융 예측 모델 비교
- [[금융 시계열 분석]] → 가격·수익률의 시간적 구조 분석

두 과목 모두 Python을 사용하므로 초반 학습 부담이 겹칠 수 있다. Python 과목에서 배운 내용을 같은 주에 금융 데이터로 다시 실습하면 효과적이다.

## 사례 3: Python은 알지만 통계가 부족한 경우

### 추천 조합

**[[00. 엑셀통계분석 목차]] + [[스마트금융데이터분석 목차]]**

변수와 자료형, 조건문, 반복문, 함수, NumPy, pandas와 기본 시각화를 이미 알고 있다면 Python 과목의 초반 수업은 중복될 수 있다.

이 경우 Excel 과목으로 추정, 검정, 회귀의 의미를 보완하고 스마트금융 과목에서 Python 지식을 응용하는 편이 효율적이다.

### 학습 초점

- 통계량과 모수의 구분
- 신뢰구간의 의미
- [[p값]]의 올바른 해석
- 회귀계수와 결정계수의 해석
- 분석 가정과 가정 위반의 영향

## 사례 4: 금융권 취업이나 금융 데이터 분석이 목표인 경우

### 추천 조합

**[[00. 파이썬데이터분석 목차]] + [[스마트금융데이터분석 목차]]**

금융 데이터 분석에서는 Excel도 사용하지만 반복적인 데이터 처리와 모델링에는 Python 활용 가치가 크다.

```text
Python 문법
→ pandas 데이터 처리
→ 데이터 시각화
→ 금융 데이터 전처리
→ 회귀·분류·군집분석
→ 텍스트 마이닝
→ 시계열 분석
```

### 적합한 진로

- 금융 데이터 분석
- 핀테크 서비스 기획·분석
- 신용평가 모델링
- 금융 위험관리
- 고객 거래 분석
- 금융권 데이터 직무

## 사례 5: 대학원이나 이론 중심 학습이 목표인 경우

### 추천 조합

**[[00. 엑셀통계분석 목차]] + [[00. 파이썬데이터분석 목차]]**

대학원 수준의 데이터 분석에서는 특정 도메인보다 통계학과 프로그래밍의 기초가 더 넓게 활용된다. Excel에서 계산 절차를 익히는 데 그치지 않고 [[수리통계학 목차]]와 연결해 수식으로 다시 공부해야 한다.

### 추가 학습 순서

`[[확률변수]] → [[기댓값]] → [[분산]] → [[표본분포]] → [[중심극한정리]] → [[가설검정]] → [[최소제곱법]] → [[다중선형회귀]]`

[[스마트금융데이터분석 목차]]는 연구 분야가 금융일 때 선택하거나 기초 과정을 마친 뒤 수강하는 편이 좋다.

## 사례 6: 실무에서 Excel을 많이 사용하는 경우

### 추천 조합

**[[00. 엑셀통계분석 목차]] + [[00. 파이썬데이터분석 목차]]**

- 소규모 자료의 빠른 검토: Excel
- 반복적인 전처리: Python
- 통계 결과의 즉각적인 확인: Excel
- 대량 파일 통합: Python
- 일회성 보고서: Excel
- 재현 가능한 정기 분석: Python

같은 자료에 대해 평균, 표준편차, 상관계수, 회귀계수를 각각 계산하여 Excel과 Python의 결과가 일치하는지 검산하는 연습이 좋다.

## 사례 7: 투자 데이터와 시계열 분석이 가장 궁금한 경우

### 추천 조합

**[[00. 파이썬데이터분석 목차]] + [[스마트금융데이터분석 목차]]**

가격과 수익률은 시간 순서를 가진 데이터다. Excel로도 간단한 분석은 가능하지만 여러 종목과 긴 기간을 처리하려면 Python이 더 적합하다.

### 주의할 점

- 미래 데이터를 과거 모델 학습에 사용하지 않는다.
- 시계열을 무작위로 섞지 않는다.
- 수정주가와 원가격을 구분한다.
- 수익률과 가격을 구분한다.
- 거래 비용을 무시한 성능을 실제 수익으로 해석하지 않는다.
- 예측 결과를 확정적인 투자 조언으로 표현하지 않는다.

## 사례 8: 학점 관리와 수업 부담이 중요한 경우

| 과목 | 중간고사 | 기말고사 | 과제 | 출석 |
|---|---:|---:|---:|---:|
| [[00. 엑셀통계분석 목차]] | 30% | 30% | 30% | 10% |
| [[00. 파이썬데이터분석 목차]] | 40% | 40% | 10% | 10% |
| [[스마트금융데이터분석 목차]] | 35% | 35% | 20% | 10% |

### 시험에 강하고 과제를 줄이고 싶은 경우

**[[00. 파이썬데이터분석 목차]] + [[스마트금융데이터분석 목차]]**

시험 비중이 각각 80%, 70%이므로 시험 기간의 부담이 크다.

### 시험보다 과제를 통해 점수를 확보하고 싶은 경우

**[[00. 엑셀통계분석 목차]] + [[스마트금융데이터분석 목차]]**

과제 비중의 합이 상대적으로 높다. 다만 Python 기초가 없다면 스마트금융 과제를 수행하는 데 시간이 많이 필요할 수 있다.

### 안정적으로 기초부터 공부하고 싶은 경우

**[[00. 엑셀통계분석 목차]] + [[00. 파이썬데이터분석 목차]]**

통계와 코딩을 나누어 배우므로 이해 구조는 안정적이지만 Excel 과제와 Python 시험을 모두 준비해야 한다.

## 조합별 최종 평가

### [[00. 엑셀통계분석 목차]] + [[00. 파이썬데이터분석 목차]]

**통계 기초 + 범용 분석 도구**

- 가장 균형이 좋은 조합
- 데이터 분석 입문자에게 적합
- 금융 이외의 분야에도 활용 가능
- 장기적인 학습 기반이 가장 탄탄함
- 금융 특화 응용은 상대적으로 부족함

**추천도: 매우 높음**

### [[00. 파이썬데이터분석 목차]] + [[스마트금융데이터분석 목차]]

**Python 기초 + 금융 응용**

- 금융 데이터 분석 목표에 가장 직접적
- 포트폴리오와 프로젝트를 만들기 좋음
- Python 내용이 일부 중복되어 반복 학습 가능
- 통계 기초가 부족하면 공식과 결과를 피상적으로 사용할 위험이 있음

**추천도: 금융 목표라면 매우 높음**

### [[00. 엑셀통계분석 목차]] + [[스마트금융데이터분석 목차]]

**통계 기초 + 금융 응용**

- Python을 이미 아는 학생에게 효율적
- 통계 해석과 금융 적용을 함께 학습
- Python을 모르면 중간 연결 단계가 부족함
- 스마트금융 과목의 코딩 부담이 커질 수 있음

**추천도: Python 경험이 있을 때 높음**

## 최종 선택 기준

> [!question] Python으로 `DataFrame`을 만들고, 열을 선택하고, 결측값을 처리할 수 있는가?

- **아니라면:** [[00. 엑셀통계분석 목차]] + [[00. 파이썬데이터분석 목차]]
- **가능하고 금융 분야가 목표라면:** [[00. 엑셀통계분석 목차]] + [[스마트금융데이터분석 목차]]
- **통계도 이미 알고 금융 분야가 목표라면:** [[00. 파이썬데이터분석 목차]] + [[스마트금융데이터분석 목차]]
- **목표가 아직 확실하지 않다면:** [[00. 엑셀통계분석 목차]] + [[00. 파이썬데이터분석 목차]]

현재 위키의 목표가 [[수리통계학 목차]], [[회귀분석 목차]], [[머신러닝 목차]], [[딥러닝 목차]]를 연결해 대학 수준의 데이터 분석 기반을 만드는 것이므로, 특별한 선수 지식이 없다면 [[00. 엑셀통계분석 목차]]와 [[00. 파이썬데이터분석 목차]]를 가장 추천한다. 이후 [[스마트금융데이터분석 목차]]를 따라 금융 데이터를 프로젝트로 보완하는 방법이 안정적이다.
