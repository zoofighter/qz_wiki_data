## 세 과목에 모두 겹치는 부분

### 1. 데이터 분석의 기본 흐름

세 과목 모두 자료를 확인하고 요약한 뒤 관계나 패턴을 분석하고 결과를 해석하는 흐름을 가진다.

```text
문제 확인
→ 자료 구조 파악
→ 자료 요약
→ 분석 방법 적용
→ 결과 해석
```

다만 구현 도구와 강조점은 다르다.

- [[00. 엑셀통계분석 목차]]: Excel 함수와 분석 도구로 계산하고 통계적으로 해석
- [[00. 파이썬데이터분석 목차]]: Python 코드로 반복 가능한 분석 절차 구현
- [[스마트금융데이터분석 목차]]: 금융 문제에 맞게 자료와 평가 방법 수정

### 2. 자료의 요약과 기초 통계

세 과목 모두 데이터의 분포, 중심, 변동과 변수 구조를 확인하는 과정이 필요하다.

공통 핵심은 다음과 같다.

- 관측치와 변수 구분
- 평균, 중앙값, 분산, 표준편차
- 최솟값과 최댓값
- 결측값과 이상치 확인
- 범주형 변수와 수치형 변수 구분

[[00. 엑셀통계분석 목차]]에서는 [[03. 기술통계량]]의 공식과 해석이 중심이고, 나머지 두 과목에서는 분석 전처리와 탐색 과정의 일부로 사용한다.

### 3. 데이터 시각적 확인

세 과목 모두 표와 그래프를 사용해 자료를 확인한다.

- Excel: 차트와 통계 그래프를 통한 분포와 관계 확인
- Python: pandas와 시각화 라이브러리를 이용한 그래프 작성
- 스마트금융: 가격, 수익률, 거래량과 모델 결과의 금융 시각화

같은 선그래프라도 금융 시계열에서는 시간 순서를 보존하고 축의 단위와 거래일을 확인해야 한다.

### 4. 회귀분석

[[회귀분석]]은 세 강의계획서에서 가장 분명하게 겹치는 분석 방법이다.

| [[00. 파이썬데이터분석 목차]]   | 코드로 모형을 적합하고 예측·평가하는 절차 |
| [[스마트금융데이터분석 목차]] | 금융 변수를 이용한 예측과 도메인 해석   |

## [[00. 엑셀통계분석 목차]]과 [[00. 파이썬데이터분석 목차]]에만 겹치는 부분

### 1. 가설검정

두 강의계획서에는 [[가설검정]]이 명시적으로 포함된다. 스마트금융에서도 모델 해석 과정에 검정이 사용될 수 있지만 주차별 핵심 주제로 분명하게 제시되지는 않았으므로 이 영역에서는 두 과목의 교집합으로 분류한다.

#### Excel에서의 접근

- 귀무가설과 대립가설 설정
- 검정통계량과 $p$값 확인
- 유의수준과 비교
- 통계적 결론 작성

#### Python에서의 접근

- 분석할 자료를 코드로 선택
- 적절한 검정 함수 실행
- 반환되는 통계량과 $p$값 확인
- 반복 가능한 분석 코드 작성

#### 함께 들을 때의 장점

Excel에서 결과표를 먼저 읽고 Python에서 같은 검정을 재현하면 함수 사용법과 통계적 의미를 분리해서 이해할 수 있다.

### 2. 일반 데이터에 대한 통계 분석

두 과목은 금융으로 분석 대상을 제한하지 않는다. 학생 점수, 공공데이터, 설문, 판매량 등 다양한 표 형식 자료에 분석 방법을 적용할 수 있다.

이 공통점은 금융 이외의 분야로 진출하거나 아직 분석 도메인을 결정하지 않은 학습자에게 유리하다.

### 3. 회귀분석의 범용적 사용

회귀분석 자체는 세 과목 공통이지만, 금융이라는 도메인을 제외한 범용 자료에 적용한다는 점은 Excel과 Python 조합에서 더 강하게 나타난다.

> [!note] 엄밀한 분류
> 회귀분석이라는 방법은 세 과목 공통이다. 여기서 두 과목만의 공통점은 회귀를 특정 금융 문제에 한정하지 않고 일반적인 통계·데이터 분석 절차로 학습한다는 수업 맥락이다.

## [[00. 파이썬데이터분석 목차]]과 [[스마트금융데이터분석 목차]]에만 겹치는 부분

세 조합 가운데 중복이 가장 큰 조합이다.

### 1. Python 기초 문법

두 과목 모두 다음 요소를 사용하거나 초반에 다룬다.

- 변수와 자료형
- 연산자
- 조건과 반복 처리
- 함수와 모듈
- 데이터 분석 라이브러리 불러오기

스마트금융 과목에서는 Python 문법 자체보다 금융 데이터를 처리하기 위한 수단으로 빠르게 사용할 가능성이 크다.

### 2. pandas 기반 데이터 처리

두 과목 모두 표 형식 데이터를 코드로 처리한다.

- 행과 열 선택
- 변수 생성
- 정렬과 필터링
- 결측값 확인
- 그룹별 집계
- 데이터 결합
- 긴 형식과 넓은 형식 변환

Python 과목에서는 일반 원리를 배우고 스마트금융에서는 가격, 재무제표, 거래 자료에 적용한다.

### 3. 데이터 시각화

두 과목 모두 Python 그래프를 사용한다.

- 선그래프
- 막대그래프
- 히스토그램
- 산점도
- 분석 결과 시각화

스마트금융에서는 시간축, 가격과 수익률, 거래량처럼 금융 데이터에 맞는 그래프 해석이 추가된다.

### 4. 분류분석

두 과목 모두 범주를 예측하는 지도학습 문제를 다룬다.

일반 Python 과목의 예시는 합격 여부, 품종, 고객 이탈 등이 될 수 있고 스마트금융에서는 연체 여부, 신용등급, 상승·하락 방향 등을 사용할 수 있다.

평가에서는 정확도만 보지 않고 [[정밀도]], [[재현율]], [[혼동행렬]]과 클래스 불균형을 확인해야 한다.

### 5. 군집분석

정답 범주 없이 비슷한 관측치를 묶는 [[군집분석]]이 두 과목에 포함된다.

- 일반 데이터: 관측치의 패턴 탐색
- 금융 데이터: 고객 세분화, 기업 유형 구분, 자산 특성 비교

군집 결과는 자연적으로 존재하는 절대적인 집단이 아니라 선택한 변수, 스케일링과 알고리즘에 따라 달라지는 분석 결과다.

### 6. 머신러닝 모델 평가

두 과목 모두 모델을 학습하는 것에서 끝나지 않고 성능을 평가한다.

공통 점검 항목은 다음과 같다.

- 학습 데이터와 테스트 데이터 분리
- 기준 모델 설정
- 평가 지표 선택
- 과적합 확인
- 전처리 순서와 [[데이터 누수]] 점검

스마트금융에서는 시간 순서가 추가로 중요하다. 미래 자료를 이용해 과거를 예측하지 않도록 [[시계열 교차검증]]을 검토해야 한다.

## [[00. 엑셀통계분석 목차]]과 [[스마트금융데이터분석 목차]]에만 겹치는 부분

### 강의계획서상 판정

세 과목 공통인 기술통계·시각화·회귀분석을 제외하면, **Excel과 스마트금융에만 명시적으로 공통되고 Python 과목에는 없는 큰 주제는 강의계획서에서 뚜렷하게 확인되지 않는다.**

이것은 두 과목의 관련성이 없다는 뜻이 아니다. 다음과 같은 간접 연결은 강하다.

### 1. 통계 결과의 해석과 금융 적용

Excel에서 배우는 평균, 표준편차, 추정과 회귀 해석은 스마트금융에서 수익률, 변동성과 금융 변수 관계를 해석하는 기초가 된다.

다만 Python 과목도 통계 분석을 포함하므로 이 주제를 엄밀하게 두 과목만의 교집합이라고 보기는 어렵다.

### 2. 표 형식 실무 데이터 처리

두 과목 모두 기업·고객·거래처럼 행과 열로 구성된 자료를 다룰 수 있다. 그러나 Python 과목 역시 동일한 구조를 다루기 때문에 세 과목 공통 기반에 가깝다.

### 결론

Excel과 스마트금융 조합의 장점은 **중복 과목을 통한 반복 학습**보다 **통계 기초와 금융 응용의 상호 보완**에 있다.

```text
Excel에서 통계 의미 학습
→ 스마트금융에서 금융 자료에 적용
```

Python 경험이 이미 있는 학생에게는 효율적인 조합이지만, Python을 처음 배우는 학생에게는 두 과목 사이의 구현 연결이 부족할 수 있다.

### 4. 분산분석

`확률분포 → 표본분포 → 추정 → 가설검정 → 분산분석 → 회귀분석`

- 조건문과 반복문
- 함수와 모듈
- 클래스 기초

스마트금융에서도 일부 문법을 사용하지만 Python 과목은 금융에 한정하지 않고 프로그래밍 자체를 더 체계적으로 다룬다.

### 2. 파일과 공공데이터 처리

- 로컬 파일 읽기와 저장
- 공공데이터 불러오기
- 여러 데이터 형식의 구조 확인
- 범용 데이터 정제

이는 금융 외의 행정, 환경, 교통, 보건과 사회 데이터 분석으로 확장할 수 있는 능력이다.

### 3. 웹 크롤링

웹페이지에서 필요한 정보를 수집하는 기초가 명시되어 있다. 실제 수집 전 다음을 확인해야 한다.

- 사이트 이용약관
- `robots.txt`
- 요청 빈도
- 개인정보와 저작권
- 공식 API 제공 여부

### 4. 도메인에 종속되지 않은 분석 구현

같은 코드를 금융뿐 아니라 다양한 데이터에 적용할 수 있다. 분석 직무가 아직 정해지지 않은 학습자에게 가장 범용적인 고유 가치다.

## [[스마트금융데이터분석 목차]]에만 명시된 고유 영역

### 1. 금융 데이터의 구조와 해석

- 가격과 수익률
- 거래량과 시장 자료
- 기업 재무자료
- 금융 고객과 거래 자료
- 관측 시점과 실제 공개 시점

금융 데이터에서는 같은 변수라도 시간과 공개 시점에 따라 사용할 수 있는 정보가 달라진다.

### 2. 금융 텍스트 마이닝

뉴스, 공시, 보고서와 같은 비정형 자료를 분석한다.

- 문서 정제
- 단어 빈도
- 감성 분석
- 주제 탐색
- 텍스트 정보와 시장 자료 연결

텍스트가 작성된 시점과 실제 공개된 시점을 구분해야 [[금융 데이터 누수]]를 방지할 수 있다.

### 3. 금융 시계열 분석

금융 자료의 시간 의존성을 다룬다.

- 추세와 변동
- [[정상성]]
- [[자기상관]]
- 시차 변수
- 시간 순서 기반 평가

일반적인 무작위 분할보다 과거로 학습하고 미래를 평가하는 절차가 적절하다.

### 4. ARIMA 모형

[[ARIMA 모형]]은 자기회귀, 차분, 이동평균 요소를 결합하는 대표적인 시계열 모형이다.

$$
\operatorname{ARIMA}(p,d,q)
$$

$p$는 자기회귀 차수, $d$는 차분 횟수, $q$는 이동평균 차수를 나타낸다. 모형 적용 전 정상성과 잔차 구조를 점검해야 한다.

### 5. 금융적 성능 해석

모델의 통계적 성능만이 아니라 다음을 함께 고려해야 한다.

- 거래 비용
- 시장 충격
- 위험과 최대 손실
- 데이터 사용 가능 시점
- 경제적 의미

## 조합별 중복과 보완 관계

### Excel + Python

| 구분 | 내용 |
|---|---|
| 주요 중복 | 기술통계, 가설검정, 회귀분석, 결과 해석 |
| Excel의 보완 | 확률분포, 추정과 검정의 이론적 의미 |
| Python의 보완 | 코드 자동화, 데이터 수집, 재현성, 머신러닝 |
| 추천 대상 | 통계와 코딩을 모두 처음 배우는 학생 |

이 조합은 중복된 분석을 서로 다른 도구로 반복하여 이해를 강화한다.

### Python + 스마트금융

| 구분 | 내용 |
|---|---|
| 주요 중복 | Python, pandas, 시각화, 회귀, 분류, 군집, 모델 평가 |
| Python의 보완 | 범용 문법, 파일·웹 데이터 수집, 일반 분석 절차 |
| 스마트금융의 보완 | 금융 도메인, 텍스트, 시계열, ARIMA |
| 추천 대상 | 금융 데이터 분석이 목표인 학생 |

이 조합은 중복이 가장 많지만 Python 과목에서 원리를 배우고 스마트금융에서 즉시 적용할 수 있다는 장점이 있다.

### Excel + 스마트금융

| 구분 | 내용 |
|---|---|
| 주요 중복 | 기술통계, 시각화, 회귀분석 |
| Excel의 보완 | 통계 추론과 회귀 결과 해석 |
| 스마트금융의 보완 | 금융 데이터, 머신러닝, 텍스트, 시계열 |
| 추천 대상 | Python 기초를 이미 갖춘 학생 |

두 과목만의 독점 교집합은 작지만 통계 이론과 금융 응용이라는 보완성이 크다.

## 중복을 학습에 활용하는 방법

### 같은 데이터를 세 도구 관점으로 보기

하나의 자료를 다음과 같이 반복 분석할 수 있다.

1. Excel로 평균, 표준편차와 회귀 결과를 계산한다.
2. Python으로 같은 분석을 재현한다.
3. 금융 변수라면 시간 순서와 경제적 의미를 추가해 해석한다.

### 중복 내용을 건너뛰지 않기

같은 회귀분석이라도 과목별 질문이 다르다.

- Excel: 계수가 통계적으로 유의한가?
- Python: 분석 코드를 재현할 수 있는가?
- 스마트금융: 미래 시점에서도 유효하며 금융적으로 의미가 있는가?

### 고유 영역을 프로젝트로 연결하기

- Excel 고유 영역: 추정과 검정 보고서
- Python 고유 영역: 공공데이터 수집·정제 프로젝트
- 스마트금융 고유 영역: 금융 텍스트 또는 시계열 프로젝트

## 최종 결론

1. 세 과목의 핵심 공통점은 자료 요약, 시각화, 회귀분석과 결과 해석이다.
2. Excel과 Python은 가설검정과 범용 통계 분석에서 직접 겹친다.
3. Python과 스마트금융은 프로그래밍, pandas, 머신러닝에서 가장 많이 겹친다.
4. Excel과 스마트금융만의 명확한 독점 교집합은 작으며 통계 기초와 금융 응용의 보완 관계가 더 중요하다.
5. Excel의 고유 가치는 통계 추론, Python의 고유 가치는 범용 수집·구현, 스마트금융의 고유 가치는 금융 텍스트·시계열 분석이다.
