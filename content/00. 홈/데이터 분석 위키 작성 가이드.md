# 데이터 분석 위키 작성 가이드

## 핵심 규칙

1. 한 노트에는 하나의 중심 개념을 다룹니다.
2. 다른 노트는 `[[노트 이름]]`으로 연결합니다.
3. 직관, 정의, 수식, 예제, 코드, 주의점을 함께 작성합니다.
4. 표 바로 앞에는 빈 줄을 둡니다.
5. 인라인 수식은 `$...$`, 블록 수식은 `$$...$$`를 사용합니다.
6. LLM이 만든 공식, 계산, 코드, 참고문헌은 반드시 검증합니다.

## 권장 노트 구조

- 한눈에 보기
- 왜 배우는가
- 선수 지식
- 핵심 직관
- 정의
- 수식과 해석
- 단계별 예제
- 코드로 확인
- 자주 하는 실수
- 관련 개념
- 연습문제와 해설
- 참고자료

## 예제 기준

핵심 개념에는 가능하면 다음 예제를 추가합니다.

- 손으로 계산할 수 있는 작은 예제
- 그래프 또는 기하학적 직관을 주는 예제
- Python이나 R로 검증하는 예제
- 실제 데이터 분석 적용 예제
- 흔한 오해를 보여 주는 반례

## LLM 확장 절차

1. 기존 노트와 관련 목차를 먼저 읽습니다.
2. 빠진 선수 지식과 연결 개념을 찾습니다.
3. 직관과 정확한 정의를 보강합니다.
4. 검산 가능한 예제와 재현 가능한 코드를 추가합니다.
5. 수식, 코드, 링크, 출처를 검토합니다.
6. 공개 준비가 끝나면 `draft: false`로 변경합니다.
