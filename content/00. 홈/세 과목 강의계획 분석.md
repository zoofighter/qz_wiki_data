## [[엑셀통계분석 목차]] 분석

### 과목의 중심 역할

Excel을 계산 도구로 사용하면서 통계학의 기본 구조를 배우는 과목이다. 메뉴와 함수를 익히는 것도 필요하지만 핵심은 통계량의 의미, 표본에서 모집단으로 추론하는 방법, 분석 결과의 올바른 해석이다.

### 주요 학습 흐름

1. 통계학과 자료의 기본 개념
2. Excel 데이터 분석 기능과 자료 요약
3. 이산·연속 확률분포
4. [[표본분포]]와 [[중심극한정리]]
5. [[점추정]]과 [[구간추정]]
6. [[가설검정]]과 두 모집단 비교
7. [[분산분석]]
8. [[공분산과 상관계수]]
9. [[단순선형회귀]]와 [[다중선형회귀]]

### 평가 구조

| 항목 | 비율 |
|---|---:|
| 중간고사 | 30% |
| 기말고사 | 30% |
| 과제 | 30% |
| 출석 | 10% |

과제 비중이 높으므로 Excel에서 분석 절차를 직접 반복하고 결과표를 해석하는 연습이 중요하다.

### 강점

- 코딩 부담 없이 통계적 사고에 집중할 수 있다.
- [[모집단과 표본]], [[기술통계량]], 추정과 검정의 연결을 배울 수 있다.
- 회귀분석의 통계적 의미를 먼저 익힐 수 있다.
- Excel을 사용하는 일반 사무·분석 업무에 바로 적용하기 쉽다.

### 한계와 주의점

- 반복 작업과 대규모 데이터 처리의 재현성이 Python보다 낮다.
- 메뉴 사용 순서만 암기하면 통계적 가정과 해석을 놓칠 수 있다.
- Excel 출력표가 자동으로 올바른 결론을 제공하는 것은 아니다.
- 결측값, 이상치, 자료형을 사전에 점검해야 한다.

### 학습 우선순위

`[[모집단과 표본]] → [[기술통계량]] → [[확률변수]] → [[표본분포]] → [[가설검정]] → [[단순선형회귀]]`

## [[파이썬데이터분석 목차]] 분석

### 평가 구조

| 항목 | 비율 |
|---|---:|
| 중간고사 | 40% |
| 기말고사 | 40% |

시험 비중이 80%이므로 코드를 직접 작성하는 연습뿐 아니라 코드를 읽고 실행 결과를 예측하거나 오류를 찾는 연습도 필요하다.

### 강점

- 데이터 수집부터 모델 평가까지 하나의 언어로 처리한다.
- 반복 작업을 자동화하고 분석 과정을 재현할 수 있다.
- 금융, 마케팅, 공공데이터, 머신러닝 등 여러 분야로 확장할 수 있다.
- [[스마트금융데이터분석 목차]]의 직접적인 선수 과목 역할을 한다.

### 한계와 주의점

- 문법, 수집, 통계, 머신러닝을 한 학기에 모두 다뤄 범위가 넓다.
- 통계적 의미보다 라이브러리 사용법에 치우칠 수 있다.
- 코드를 복사해 실행하는 것만으로는 새로운 데이터에 적용하기 어렵다.
- 학습 데이터와 테스트 데이터의 분리, 전처리 순서와 [[데이터 누수]]를 점검해야 한다.

## [[스마트금융데이터분석 목차]] 분석

### 과목의 중심 역할

금융상품, 기업, 시장, 고객과 관련된 데이터를 대상으로 통계 분석, 머신러닝, 텍스트 마이닝과 시계열 분석을 적용하는 응용 과목이다. Python 기술만이 아니라 금융 데이터의 시간 구조와 분석 결과의 경제적 의미가 중요하다.

### 주요 학습 흐름

1. [[금융 데이터 분석 개요]]
2. [[금융 데이터의 종류와 구조]]
3. 금융 변수, 자료형, 함수와 모듈
4. NumPy와 pandas
5. 금융 데이터 정제와 결합
6. 금융 데이터 시각화
7. 머신러닝 개요와 평가
8. 금융 데이터 회귀분석
9. 의사결정나무 등 분류 방법
10. 금융 데이터 군집분석
11. 전처리와 차원 축소
12. [[금융 텍스트 마이닝]]
13. [[금융 시계열 분석]]과 [[ARIMA 모형]]

### 평가 구조

| 항목 | 비율 |
|---|---:|
| 중간고사 | 35% |
| 기말고사 | 35% |
| 과제 | 20% |
| 출석 | 10% |

시험과 과제가 모두 중요하다. 금융 데이터를 직접 처리하고 모델 결과를 해석하는 복합 문제가 중심이 될 가능성이 있다.

### 강점

- 금융이라는 구체적인 도메인에서 분석 방법을 연결한다.
- 표 형식 데이터뿐 아니라 텍스트와 시계열 데이터를 다룬다.
- 회귀, 분류, 군집, 시계열이라는 주요 문제를 폭넓게 경험한다.
- 금융 데이터 프로젝트와 포트폴리오 주제를 만들기 좋다.

### 한계와 주의점

- Python과 통계 기초가 부족하면 응용보다 기초 문법에 시간이 소모될 수 있다.
- 금융 시계열을 무작위로 분할하면 미래 정보가 과거 학습에 들어갈 수 있다.
- 가격과 수익률, 통계적 유의성과 경제적 유용성을 구분해야 한다.
- 거래 비용을 반영하지 않은 예측 성능을 실제 투자 성과로 해석하면 안 된다.
- 분석 결과는 확정적인 투자 조언이 아니다.

`[[금융 데이터 분석 개요]] → [[금융 데이터의 종류와 구조]] → [[pandas 금융 데이터 처리]] → [[금융 데이터 시각화]] → [[금융 머신러닝 모델 평가]] → [[금융 시계열 분석]]`
