# 01. 데이터베이스 기본 개념

> [!summary] 한눈에 보기
> 데이터베이스는 관련 데이터를 구조적으로 통합해 저장한 집합이고, DBMS는 이를 정의·조회·수정·보호하는 소프트웨어다. 파일을 단순히 모아 놓는 것보다 중복과 불일치를 줄이고 여러 사용자가 데이터를 공유하게 한다.

## 왜 배우는가

Excel 파일이나 CSV를 부서별로 복사하면 같은 고객의 주소가 서로 다르게 저장될 수 있다. 데이터베이스는 데이터의 구조와 제약조건을 중앙에서 관리해 일관성을 높인다.

## 핵심 용어

- **데이터:** 관측하거나 기록한 사실
- **정보:** 목적에 맞게 해석된 데이터
- **데이터베이스:** 관련 데이터의 통합된 저장소
- **DBMS:** 데이터베이스를 관리하는 소프트웨어
- **스키마:** 데이터 구조와 제약조건의 정의
- **인스턴스:** 특정 시점에 저장된 실제 데이터
- **메타데이터:** 데이터의 구조와 의미를 설명하는 데이터

## 파일 시스템과 비교

| 구분 | 파일 중심 관리 | 데이터베이스 관리 |
|---|---|---|
| 중복 | 프로그램별 파일에 반복 저장 | 통합 설계로 중복 감소 |
| 일관성 | 사본마다 값이 달라질 수 있음 | 제약조건과 트랜잭션으로 관리 |
| 공유 | 동시 사용과 권한 관리가 어려움 | 다중 사용자와 권한 지원 |
| 질의 | 프로그램을 직접 작성 | SQL로 선언적 조회 |
| 회복 | 별도 백업 절차 필요 | 로그와 회복 기능 제공 |

## 데이터베이스의 주요 특성

- 실시간 접근
- 지속적인 변화
- 여러 사용자의 동시 공유
- 내용에 의한 참조
- 데이터 독립성

## 실제 적용

- 대학 수강신청과 성적 관리
- 은행 계좌와 거래 처리
- 쇼핑몰 상품·주문·회원 관리
- 병원 환자와 진료 기록
- 분석용 데이터웨어하우스

## 자주 하는 실수

- 데이터베이스와 DBMS를 같은 용어로 사용한다.
- 스키마와 실제 저장값을 구분하지 않는다.
- 데이터베이스를 단순한 큰 Excel 파일로 생각한다.
- 중앙 저장소만 만들면 자동으로 데이터 품질이 좋아진다고 생각한다.
