# 04. 관계 데이터 모델

> [!summary] 한눈에 보기
> 관계 데이터 모델은 데이터를 행과 열로 구성된 릴레이션으로 표현한다. 키와 무결성 제약조건을 통해 행을 식별하고 테이블 사이의 관계를 유지한다.

## 핵심 용어

- **릴레이션:** 테이블에 대응하는 수학적 관계
- **튜플:** 한 행
- **속성:** 한 열
- **도메인:** 속성이 가질 수 있는 값의 집합
- **차수:** 속성 수
- **카디널리티:** 튜플 수

## 키의 종류

- **슈퍼키:** 튜플을 유일하게 식별하는 속성 집합
- **후보키:** 불필요한 속성이 없는 최소 슈퍼키
- **기본키:** 후보키 중 대표로 선택한 키
- **대체키:** 선택되지 않은 후보키
- **외래키:** 다른 릴레이션의 기본키를 참조하는 속성

## 무결성 제약조건

### 개체 무결성

기본키는 `NULL`일 수 없고 중복될 수 없다.

### 참조 무결성

외래키 값은 참조 대상 기본키에 존재하거나 허용된 경우 `NULL`이어야 한다.

### 도메인 무결성

각 속성 값은 정의된 자료형, 범위와 형식을 만족해야 한다.

## 예제 스키마

```sql
CREATE TABLE students (
    student_id INTEGER PRIMARY KEY,
    name VARCHAR(50) NOT NULL,
    email VARCHAR(100) UNIQUE
);

CREATE TABLE enrollments (
    student_id INTEGER NOT NULL,
    course_id INTEGER NOT NULL,
    grade VARCHAR(2),
    PRIMARY KEY (student_id, course_id),
    FOREIGN KEY (student_id) REFERENCES students(student_id)
);
```

외래키 강제 여부와 자료형 문법은 DBMS 설정에 따라 차이가 있을 수 있다.

## 자주 하는 실수

- 기본키를 업무상 변경 가능한 이름이나 전화번호로 선택한다.
- `NULL`, $0$, 빈 문자열을 같은 값으로 생각한다.
- 외래키만 만들면 모든 업무 규칙이 표현된다고 생각한다.
