# 06. SQL 기초

> [!summary] 한눈에 보기
> SQL은 관계형 데이터베이스의 구조를 정의하고 데이터를 조회·변경하는 선언적 언어다. 원하는 결과를 기술하면 DBMS가 실행 계획을 선택한다.

## SQL 명령 분류

- **DDL:** `CREATE`, `ALTER`, `DROP`
- **DML:** `SELECT`, `INSERT`, `UPDATE`, `DELETE`
- **DCL:** `GRANT`, `REVOKE`
- **TCL:** `COMMIT`, `ROLLBACK`

## 재현 가능한 예제

```sql
CREATE TABLE products (
    product_id INTEGER PRIMARY KEY,
    product_name VARCHAR(100) NOT NULL,
    category VARCHAR(50) NOT NULL,
    price DECIMAL(10, 2) NOT NULL CHECK (price >= 0)
);

INSERT INTO products (product_id, product_name, category, price)
VALUES
    (1, '노트북', '전자기기', 1200000),
    (2, '키보드', '전자기기', 80000),
    (3, '통계학 교재', '도서', 35000);
```

## 기본 조회

```sql
SELECT product_id, product_name, price
FROM products
WHERE category = '전자기기'
ORDER BY price DESC;
```

## 집계

```sql
SELECT
    category,
    COUNT(*) AS product_count,
    AVG(price) AS average_price
FROM products
GROUP BY category
HAVING COUNT(*) >= 1;
```

`WHERE`는 그룹화 전의 행을 필터링하고 `HAVING`은 집계된 그룹을 필터링한다.

## NULL 처리

```sql
SELECT *
FROM products
WHERE price IS NULL;
```

`NULL`은 알 수 없거나 적용되지 않는 값을 나타내며 `price = NULL`로 비교하지 않는다.

## 데이터 변경 안전 원칙

```sql
SELECT * FROM products WHERE product_id = 3;

UPDATE products
SET price = 38000
WHERE product_id = 3;
```

`UPDATE`나 `DELETE` 전에는 같은 `WHERE` 조건의 `SELECT`로 대상을 확인한다.

## 자주 하는 실수

- 문자열에 작은따옴표를 사용하지 않는다.
- `WHERE` 없는 `UPDATE`나 `DELETE`를 실행한다.
- `NULL`을 $0$과 같은 값으로 처리한다.
- `GROUP BY`와 집계함수의 관계를 이해하지 않고 열을 추가한다.
