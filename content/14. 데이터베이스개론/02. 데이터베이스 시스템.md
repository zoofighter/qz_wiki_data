# 02. 데이터베이스 시스템

> [!summary] 한눈에 보기
> 데이터베이스 시스템은 데이터베이스, DBMS, 사용자, 응용프로그램과 하드웨어를 포함하는 전체 환경이다. DBMS 내부에서는 질의 처리, 저장 관리, 트랜잭션과 보안 기능이 협력한다.

## 구성 요소

- 데이터베이스
- DBMS
- 데이터베이스 관리자
- 응용프로그램 개발자
- 일반 사용자와 분석가
- 저장장치와 서버

## 3단계 스키마 구조

### 외부 단계

사용자나 응용프로그램별로 필요한 데이터만 보는 뷰다.

### 개념 단계

전체 데이터베이스의 논리 구조와 관계를 정의한다.

### 내부 단계

파일, 인덱스와 저장 위치 등 물리적 저장 구조를 다룬다.

## 데이터 독립성

- **논리적 데이터 독립성:** 개념 스키마가 바뀌어도 외부 뷰와 응용프로그램의 변경을 최소화한다.
- **물리적 데이터 독립성:** 인덱스나 파일 구조가 바뀌어도 논리 스키마를 유지한다.

## DBMS의 주요 모듈

- SQL 파서와 최적화기
- 실행 엔진
- 저장 관리자
- 버퍼 관리자
- 트랜잭션 관리자
- 회복 관리자
- 권한 관리자

## 질의 처리 흐름

```text
SQL 입력
→ 문법·의미 검사
→ 실행 계획 생성과 비용 비교
→ 연산 실행
→ 결과 반환
```

같은 결과를 만드는 SQL도 실행 계획에 따라 성능이 달라질 수 있다.

## 자주 하는 실수

- 데이터베이스 시스템을 서버 하드웨어만으로 생각한다.
- 논리 구조와 물리 저장 구조를 혼동한다.
- 인덱스를 추가하면 모든 질의와 쓰기 성능이 향상된다고 생각한다.
