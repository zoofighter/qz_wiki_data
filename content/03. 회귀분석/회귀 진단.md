# 회귀 진단

> [!summary] 한눈에 보기
> 회귀 진단은 잔차, 영향력, 공선성, 예측 성능을 살펴보며 [[회귀모형의 가정]]과 모델의 안정성을 평가하는 과정이다. 하나의 검정 결과보다 그래프, 수치 지표, 데이터 생성 과정을 함께 판단해야 한다.

## 왜 배우는가

높은 $R^2$나 작은 $p$값만으로 좋은 회귀모형을 보장할 수 없다. 잘못된 함수 형태, 이상치, 이분산성, 자기상관, 다중공선성은 계수와 불확실성 해석을 왜곡할 수 있다.

## 기본 잔차

관측값과 적합값의 차이는 잔차다.

$$
e_i=y_i-\hat{y}_i
$$

잔차 크기는 관측값마다 분산이 다를 수 있으므로 표준화 잔차나 스튜던트화 잔차를 함께 사용한다.

## 핵심 진단 그래프

### 잔차 대 적합값

- 무작위 띠: 선형성과 등분산성에 큰 문제가 보이지 않는다.
- 곡선 패턴: 비선형 관계나 누락된 변환을 의심한다.
- 부채꼴 패턴: [[이분산성]]을 의심한다.
- 고립된 큰 잔차: 이상치 가능성을 검토한다.

### 정규 Q-Q plot

잔차 분위수와 정규분포 분위수를 비교한다. 꼬리 부분이 직선에서 크게 벗어나면 두꺼운 꼬리나 이상치를 의심한다. 정규성은 특히 작은 표본의 정확한 추론과 관련된다.

### Scale-Location plot

표준화 잔차 절댓값의 제곱근과 적합값을 비교해 분산의 일정성을 확인한다.

### 잔차 대 레버리지

설명변수 공간에서 특이한 관측값과 반응변수 방향의 큰 잔차가 결합되는지 확인한다.

## 영향력 지표

### 레버리지

Hat matrix는 다음과 같다.

$$
\mathbf{H}
=\mathbf{X}(\mathbf{X}^{\mathsf{T}}\mathbf{X})^{-1}
\mathbf{X}^{\mathsf{T}}
$$

대각원소 $h_{ii}$가 레버리지다. 설명변수 공간에서 중심에서 멀수록 레버리지가 커질 수 있다.

### Cook 거리

관측값 하나를 제거했을 때 전체 적합값이 얼마나 변하는지를 요약한다. 큰 Cook 거리는 조사할 후보이지 자동 삭제 기준이 아니다.

## 다중공선성 진단

분산팽창계수는 다음과 같다.

$$
\operatorname{VIF}_j=\frac{1}{1-R_j^2}
$$

$R_j^2$는 $j$번째 설명변수를 나머지 설명변수로 회귀했을 때의 결정계수다. VIF가 크면 해당 계수의 분산이 공선성 때문에 증가했음을 의미한다. 특정 임계값만 기계적으로 적용하지 말고 연구 목적과 계수 안정성을 함께 본다.

## 단계별 진단 절차

1. 데이터 입력 오류와 단위를 확인한다.
2. 반응변수와 각 설명변수의 분포를 본다.
3. 잔차 대 적합값 그래프로 함수 형태와 분산을 확인한다.
4. Q-Q plot으로 잔차 꼬리와 이상치를 확인한다.
5. 레버리지와 Cook 거리로 영향점을 찾는다.
6. VIF와 조건수를 통해 공선성을 확인한다.
7. 교차검증이나 테스트 데이터로 일반화 성능을 평가한다.
8. 문제 발견 시 원인을 조사하고 변환, 변수 추가, 강건 표준오차, 다른 모형을 검토한다.

## 코드로 확인

```python
import matplotlib.pyplot as plt
import numpy as np

x = np.array([1, 2, 3, 4, 5, 6], dtype=float)
y = np.array([2, 4, 5, 8, 10, 18], dtype=float)
design_matrix = np.column_stack([np.ones_like(x), x])

coefficients, _, _, _ = np.linalg.lstsq(
    design_matrix,
    y,
    rcond=None,
)
fitted_values = design_matrix @ coefficients
residuals = y - fitted_values

fig, axis = plt.subplots()
axis.axhline(0, color="black", linewidth=1)
axis.scatter(fitted_values, residuals)
axis.set_xlabel("Fitted values")
axis.set_ylabel("Residuals")
plt.show()
```

마지막 관측값이 회귀선과 모델 계수에 큰 영향을 주는지 원자료, 레버리지, Cook 거리를 추가로 확인해야 한다.

## 문제 발견 후 대응

| 문제 | 검토할 대응 |
|---|---|
| 비선형 패턴 | 변수 변환, 다항항, 스플라인, 다른 모델 |
| 이분산성 | 강건 표준오차, 변수 변환, 가중최소제곱 |
| 자기상관 | 시계열 구조, 군집 표준오차, 적절한 오차모형 |
| 다중공선성 | 변수 재설계, 추가 데이터, 정규화 회귀 |
| 영향점 | 입력 오류 확인, 민감도 분석, 강건 회귀 |

## 이상치를 삭제하기 전 질문

- 데이터 입력이나 측정 오류인가?
- 모집단에서 실제로 가능한 관측값인가?
- 분석 대상 모집단에 포함되어야 하는가?
- 제거 전후 결론이 얼마나 달라지는가?
- 삭제 기준을 결과를 보기 전에 정했는가?

정당한 근거 없이 결과를 좋게 만들기 위해 관측값을 삭제해서는 안 된다.

## 자주 하는 실수

- 진단 검정의 $p$값만 보고 그래프와 맥락을 무시한다.
- 큰 잔차나 Cook 거리를 가진 관측값을 자동으로 삭제한다.
- 훈련 데이터의 잔차 진단만으로 외부 예측 성능을 판단한다.
- 다중공선성을 단순 상관계수만으로 평가한다.
- 문제를 발견한 뒤 최종 모형 선택 과정을 기록하지 않는다.

잔차 대 적합값 그래프에서 다음 패턴을 발견했을 때 가능한 원인과 대응을 하나씩 제시하라.

1. U자형 패턴
2. 오른쪽으로 갈수록 넓어지는 부채꼴
