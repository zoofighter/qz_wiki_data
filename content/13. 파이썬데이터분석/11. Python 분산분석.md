# 11. Python 분산분석

> [!summary] 한눈에 보기
> 일원분산분석은 세 집단 이상 평균의 동일성을 검정한다. 유의한 결과가 나오면 어떤 집단 차이가 있는지 사후비교와 효과크기를 추가로 확인한다.

## 일원분산분석

```python
import numpy as np
from scipy import stats

group_a = np.array([70.0, 72.0, 68.0, 75.0])
group_b = np.array([80.0, 78.0, 82.0, 79.0])
group_c = np.array([76.0, 74.0, 77.0, 75.0])

result = stats.f_oneway(group_a, group_b, group_c)

print(result.statistic)
print(result.pvalue)
```

## 가정 점검

- 관측의 독립성은 자료 수집 설계에서 확인한다.
- 집단별 분포와 이상치를 그래프로 확인한다.
- 분산 동질성 위반이 크면 Welch ANOVA 등 대안을 검토한다.

## 긴 형식 데이터

```python
import pandas as pd

data = pd.DataFrame({
    "group": ["A"] * 4 + ["B"] * 4 + ["C"] * 4,
    "score": np.concatenate([group_a, group_b, group_c]),
})

print(data.groupby("group")["score"].agg(["count", "mean", "std"]))
```

## 자주 하는 실수

- 유의한 결과를 모든 집단이 다르다는 뜻으로 해석한다.
- 사후비교의 다중검정 문제를 무시한다.
- 반복측정 자료에 독립표본 ANOVA를 적용한다.
- 표본 수가 매우 다른 집단의 분산 차이를 확인하지 않는다.
