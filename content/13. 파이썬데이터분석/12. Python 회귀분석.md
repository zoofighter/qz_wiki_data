# 12. Python 회귀분석

> [!summary] 한눈에 보기
> 선형회귀는 설명변수와 연속형 반응변수의 관계를 모형화한다. 예측 목적에서는 학습·테스트 데이터를 분리하고, 추론 목적에서는 계수의 가정과 불확실성을 확인한다.

## 재현 가능한 예제

```python
import numpy as np
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error, r2_score

hours = np.array([1, 2, 3, 4, 5, 6], dtype=float).reshape(-1, 1)
scores = np.array([52, 58, 65, 72, 78, 85], dtype=float)

model = LinearRegression()
model.fit(hours, scores)

predictions = model.predict(hours)

print(model.intercept_)
print(model.coef_)
print(mean_squared_error(scores, predictions))
print(r2_score(scores, predictions))
```

출력은 실제 환경에서 실행해 확인한다. 같은 데이터로 학습과 평가를 모두 수행했으므로 이 예제의 지표는 일반화 성능이 아니다.

## 학습·테스트 분할

```python
from sklearn.model_selection import train_test_split

features_train, features_test, target_train, target_test = train_test_split(
    hours,
    scores,
    test_size=0.33,
    random_state=42,
)
```

시계열 자료에는 무작위 분할을 그대로 사용하지 않는다.

## 점검 사항

- 잔차의 선형성과 등분산성
- 이상치와 영향점
- 설명변수 사이의 다중공선성
- 학습 데이터와 테스트 데이터의 성능 차이
- 계수의 단위와 조건부 해석
