# 04. Python 조건문과 반복문

> [!summary] 한눈에 보기
> 조건문은 조건에 따라 실행 경로를 선택하고 반복문은 같은 규칙을 여러 값에 적용한다. Python에서는 들여쓰기가 코드 블록의 구조를 결정한다.

## 조건문

```python
score = 85

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
else:
    grade = "C"

print(grade)
```

## for 반복문

```python
scores = [80, 92, 75]

for score in scores:
    print(score, score >= 80)
```

## while 반복문

```python
count = 0

while count < 3:
    print(count)
    count += 1
```

종료 조건이 변하지 않으면 무한 반복이 발생한다.

## 리스트 컴프리헨션

```python
scores = [80, 92, 75]
passed_scores = [score for score in scores if score >= 80]

print(passed_scores)
```

복잡한 조건과 여러 부작용이 있는 작업은 일반 반복문이 더 읽기 쉽다.

## 자주 하는 실수

- 대입 `=`와 비교 `==`를 혼동한다.
- 들여쓰기를 일관되지 않게 사용한다.
- 반복 중 리스트의 길이를 변경한다.
- pandas 데이터를 불필요하게 행 단위 반복문으로 처리한다.
