# 05. Python 함수와 입출력

> [!summary] 한눈에 보기
> 함수는 입력을 받아 정해진 작업을 수행하고 결과를 반환하는 재사용 가능한 단위다. 파일 입출력에서는 인코딩, 경로와 자원 해제를 명시해야 한다.

## 함수 정의

```python
def calculate_mean(values):
    if not values:
        raise ValueError("values must not be empty")
    return sum(values) / len(values)


scores = [80, 92, 75]
print(calculate_mean(scores))
```

함수의 입력 조건과 반환값을 명확히 정한다.

## 여러 값 반환

```python
def summarize(values):
    return min(values), max(values), sum(values) / len(values)


minimum, maximum, mean_value = summarize([3, 5, 7])
print(minimum, maximum, mean_value)
```

## 텍스트 파일 읽기

```python
from pathlib import Path

file_path = Path("data") / "sample.txt"

with file_path.open("r", encoding="utf-8") as file:
    text = file.read()

print(text)
```

`with` 블록이 끝나면 파일이 자동으로 닫힌다. 실제 실행에는 입력 파일이 필요하다.

## CSV와 pandas

```python
import pandas as pd

data = pd.read_csv("data/sales.csv", encoding="utf-8")
print(data.head())
```

구분자, 인코딩, 날짜와 결측값 표현은 파일마다 확인해야 한다.

## 자주 하는 실수

- 함수 안에서 출력만 하고 결과를 `return`하지 않는다.
- 변경 가능한 객체를 기본 인수로 사용한다.
- 절대경로를 개인 컴퓨터에 고정한다.
- 입력 파일의 인코딩과 열 자료형을 확인하지 않는다.
