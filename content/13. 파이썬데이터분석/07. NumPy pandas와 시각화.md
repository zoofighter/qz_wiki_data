# 07. NumPy pandas와 시각화

> [!summary] 한눈에 보기
> NumPy 배열은 같은 자료형의 수치 계산에 적합하고 pandas DataFrame은 이름이 있는 열과 서로 다른 자료형을 다룬다. 시각화는 분석 전에 분포와 관계, 오류를 확인하는 도구다.

## NumPy 배열

```python
import numpy as np

scores = np.array([80, 92, 75, 88], dtype=float)

print(scores.mean())
print(scores.std(ddof=1))
print(scores[scores >= 80])
```

`ddof=1`은 표본표준편차 계산에 사용한다.

## pandas DataFrame

```python
import pandas as pd

students = pd.DataFrame({
    "group": ["A", "A", "B", "B"],
    "score": [80, 92, 75, 88],
    "hours": [3.0, 5.0, 2.0, 4.0],
})

print(students.dtypes)
print(students.groupby("group")["score"].mean())
```

## 시각화

```python
import matplotlib.pyplot as plt

students.plot.scatter(x="hours", y="score")
plt.title("Study Hours and Score")
plt.tight_layout()
plt.show()
```

코드 실행 시 그래프 창이나 Notebook 출력 영역에 산점도가 생성된다.

## 데이터 선택

```python
selected = students.loc[
    students["score"] >= 80,
    ["group", "score"],
]

print(selected)
```

## 자주 하는 실수

- NumPy의 `*`를 행렬곱으로 생각한다.
- pandas 인덱스와 실제 식별자를 같은 것으로 간주한다.
- 결측값과 자료형을 확인하지 않고 평균을 계산한다.
- 그래프 축, 단위와 표본 크기를 표시하지 않는다.
