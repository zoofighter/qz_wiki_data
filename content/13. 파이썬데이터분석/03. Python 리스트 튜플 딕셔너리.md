# 03. Python 리스트 튜플 딕셔너리

> [!summary] 한눈에 보기
> 리스트와 튜플은 순서가 있는 값의 모음이고 딕셔너리는 키와 값의 대응을 저장한다. 데이터의 의미와 변경 가능성에 맞는 자료구조를 선택해야 한다.

## 리스트

```python
scores = [80, 92, 75]

scores.append(88)
scores[0] = 82

print(scores)
print(scores[1:3])
```

리스트는 변경 가능하고 중복 값을 허용한다. 인덱스는 $0$부터 시작한다.

## 튜플

```python
coordinate = (37.5, 127.0)
latitude, longitude = coordinate

print(latitude)
print(longitude)
```

튜플은 생성 후 원소를 변경할 수 없다. 좌표나 함수가 반환하는 여러 값처럼 구조가 고정된 자료에 적합하다.

## 딕셔너리

```python
student = {
    "student_id": 1,
    "name": "Kim",
    "score": 90,
}

student["score"] = 95
student["group"] = "A"

print(student["name"])
print(student.get("email"))
```

키는 중복될 수 없으며 `get()`은 키가 없을 때 오류 대신 기본값을 반환할 수 있다.

## 반복과 집계

```python
scores = [80, 92, 75, 88]
mean_score = sum(scores) / len(scores)

print(mean_score)
```

## 자주 하는 실수

- 첫 번째 원소의 인덱스를 $1$로 생각한다.
- 튜플의 원소를 직접 변경하려 한다.
- 딕셔너리 키와 리스트 인덱스를 같은 방식으로 사용한다.
- 숫자와 결측값이 섞인 리스트의 평균을 바로 계산한다.
