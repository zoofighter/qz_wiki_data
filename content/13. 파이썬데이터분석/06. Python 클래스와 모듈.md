# 06. Python 클래스와 모듈

> [!summary] 한눈에 보기
> 클래스는 데이터와 동작을 하나의 객체로 묶고 모듈은 관련 함수와 클래스를 파일 단위로 정리한다. 데이터 분석 입문에서는 기존 라이브러리 객체의 속성과 메서드를 이해하는 것이 우선이다.

## 클래스 예제

```python
class DatasetSummary:
    def __init__(self, values):
        self.values = values

    def mean(self):
        return sum(self.values) / len(self.values)


summary = DatasetSummary([10, 20, 30])
print(summary.mean())
```

`self`는 생성된 객체 자신을 가리킨다.

## 모듈 사용

```python
import math

standard_error = 12 / math.sqrt(36)
print(standard_error)
```

필요한 이름만 가져올 수도 있다.

```python
from statistics import mean

print(mean([10, 20, 30]))
```

## 패키지와 라이브러리

- NumPy: 수치 배열과 선형대수
- pandas: 표 형식 데이터
- Matplotlib: 시각화
- SciPy: 과학계산과 통계
- scikit-learn: 머신러닝

패키지의 함수와 옵션은 설치된 버전의 공식 문서를 확인한다.

## 자주 하는 실수

- 단순한 계산까지 불필요한 클래스로 만든다.
- 모듈 파일 이름을 `pandas.py`, `statistics.py`처럼 라이브러리와 같게 만든다.
- `import *`를 사용해 이름의 출처를 알기 어렵게 한다.
- 객체의 속성과 메서드 호출을 혼동한다.
