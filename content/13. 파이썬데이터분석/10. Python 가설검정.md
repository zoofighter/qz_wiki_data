# 10. Python 가설검정

> [!summary] 한눈에 보기
> Python 가설검정에서는 연구 질문과 표본 구조에 맞는 검정을 선택하고 함수가 반환하는 통계량과 $p$값을 해석한다. 검정 전 독립성, 분포와 대응 여부를 확인한다.

## 한 표본 $t$검정

```python
import numpy as np
from scipy import stats

scores = np.array([52.0, 49.0, 55.0, 51.0, 53.0])
result = stats.ttest_1samp(scores, popmean=50.0)

print(result.statistic)
print(result.pvalue)
```

## 독립표본 Welch $t$검정

```python
group_a = np.array([80.0, 82.0, 79.0, 90.0])
group_b = np.array([75.0, 77.0, 74.0, 78.0, 81.0])

result = stats.ttest_ind(
    group_a,
    group_b,
    equal_var=False,
)

print(result.statistic)
print(result.pvalue)
```

## 대응표본 검정

```python
before = np.array([70.0, 65.0, 80.0, 75.0])
after = np.array([74.0, 68.0, 82.0, 79.0])

result = stats.ttest_rel(before, after)
print(result)
```

행 순서가 같은 대상을 나타내는지 확인해야 한다.

## 해석 원칙

- 유의수준을 분석 전에 정한다.
- $p$값과 함께 차이의 크기와 신뢰구간을 제시한다.
- 유의하지 않다는 결과를 동일성의 증명으로 해석하지 않는다.
- 다중검정을 수행하면 오류율 증가를 고려한다.
