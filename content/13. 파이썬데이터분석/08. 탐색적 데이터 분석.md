# 08. 탐색적 데이터 분석

> [!summary] 한눈에 보기
> 탐색적 데이터 분석은 모델을 적용하기 전에 데이터의 구조, 분포, 결측값, 이상치와 변수 관계를 조사하는 과정이다. EDA에서 발견한 패턴을 확정적인 가설검정 결과로 표현해서는 안 된다.

## 기본 점검 코드

```python
import pandas as pd

data = pd.DataFrame({
    "group": ["A", "A", "B", "B", None],
    "score": [80, 92, 75, 88, 300],
    "hours": [3.0, 5.0, 2.0, None, 4.0],
})

print(data.shape)
print(data.dtypes)
print(data.isna().sum())
print(data.describe(include="all"))
```

## 연속형 데이터 확인

- 평균과 중앙값
- 표준편차와 사분위범위
- 최솟값과 최댓값
- 히스토그램과 상자그림
- 변수 간 산점도와 상관계수

```python
import matplotlib.pyplot as plt

data["score"].plot.hist(bins=5, edgecolor="black")
plt.xlabel("score")
plt.tight_layout()
plt.show()
```

## 이상치 처리

이상치는 입력 오류일 수도 있고 중요한 실제 사건일 수도 있다. 삭제 전 다음을 확인한다.

- 가능한 값과 단위인가?
- 수집 과정에 오류가 있었는가?
- 분석 목적상 중요한 집단인가?
- 결과가 특정 값에 과도하게 의존하는가?

## 자주 하는 실수

- 그래프를 본 뒤 세운 가설을 사전 가설처럼 검정한다.
- 결측값을 무조건 평균으로 채운다.
- 이상치를 이유 없이 삭제한다.
- 학습·테스트 분할 전에 전체 데이터로 전처리 기준을 계산한다.
