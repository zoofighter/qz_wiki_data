# 09. Python 확률분포와 통계적 추론

> [!summary] 한눈에 보기
> Python에서는 확률분포의 확률, 분위수와 난수를 계산하고 모의실험으로 표본분포를 확인할 수 있다. 난수 실험은 seed와 반복 횟수를 기록해야 한다.

## 정규분포 계산

```python
from scipy import stats

probability = stats.norm.cdf(80, loc=70, scale=10)
critical_value = stats.norm.ppf(0.975)

print(probability)
print(critical_value)
```

`cdf`는 누적확률, `ppf`는 분위수를 계산한다.

## 중심극한정리 모의실험

```python
import numpy as np

rng = np.random.default_rng(seed=42)
sample_size = 30
repetitions = 10_000

samples = rng.exponential(
    scale=1.0,
    size=(repetitions, sample_size),
)
sample_means = samples.mean(axis=1)

print(sample_means.mean())
print(sample_means.std(ddof=0))
```

실행 결과는 환경에서 확인해야 하며, 이론적 표준오차 $1/\sqrt{30}$과 비교할 수 있다.

## 평균 신뢰구간

```python
import numpy as np
from scipy import stats

values = np.array([12.0, 15.0, 14.0, 10.0, 16.0])
n = len(values)
mean_value = values.mean()
standard_error = stats.sem(values)
critical_value = stats.t.ppf(0.975, df=n - 1)

confidence_interval = (
    mean_value - critical_value * standard_error,
    mean_value + critical_value * standard_error,
)

print(confidence_interval)
```

## 자주 하는 실수

- `scale`에 분산을 넣고 표준편차로 착각한다.
- 난수 seed 없이 결과를 비교한다.
- 신뢰구간의 가정과 표본추출 방식을 확인하지 않는다.
- 시뮬레이션 결과를 이론적 증명으로 생각한다.
