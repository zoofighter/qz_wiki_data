# 금융 데이터의 종류와 구조

> [!summary] 한눈에 보기
> 금융 데이터는 시장 시계열, 기업 재무자료, 고객·거래 자료, 텍스트 자료 등으로 구분할 수 있다. 분석 전에 한 행이 무엇을 나타내는지, 시간 단위가 무엇인지, 값이 언제 관측·공개되었는지를 확인해야 한다.

## 왜 배우는가

같은 숫자라도 데이터 구조에 따라 분석 단위가 달라진다. 일별 주가의 한 행은 특정 날짜를 나타내지만 고객 거래 데이터의 한 행은 한 번의 결제를 나타낼 수 있다. 분석 단위를 잘못 이해하면 평균, 표본 크기, 학습·테스트 분할이 모두 잘못된다.

## 대표적인 금융 데이터

| 구분 | 관측 단위 예 | 주요 변수 예 | 주요 분석 |
|---|---|---|---|
| 시장 데이터 | 종목-시각 | 가격, 거래량, 호가 | 수익률·변동성·시계열 |
| 기업 데이터 | 기업-분기 | 매출, 부채, 이익 | 기업 비교·부도 위험 |
| 고객 데이터 | 고객 | 연령대, 잔액, 상품 수 | 고객 분류·이탈 예측 |
| 거래 데이터 | 거래 한 건 | 금액, 시간, 가맹점 | 이상 탐지·소비 분석 |
| 텍스트 데이터 | 문서 | 뉴스, 공시, 보고서 | 감성·주제 분석 |

## 횡단면·시계열·패널

### 횡단면 데이터

한 시점 또는 비슷한 시기에 여러 대상을 관측한다. 예를 들어 같은 분기의 여러 기업 부채비율을 비교하는 자료다.

### 시계열 데이터

한 대상을 여러 시점에 걸쳐 관측한다. 일별 환율이나 월별 기준금리가 대표적이다. 인접 관측치가 서로 관련될 수 있으므로 [[독립성]]을 자동으로 가정하면 안 된다.

### 패널 데이터

여러 대상을 여러 시점에 반복 관측한다. 기업별 분기 재무자료처럼 개체 차이와 시간 변화를 함께 포함한다.

## 긴 형식과 넓은 형식

긴 형식에서는 각 행이 하나의 `대상-시점` 관측을 나타낸다.

| date | asset | price |
|---|---|---:|
| 2026-08-03 | A | 100 |
| 2026-08-03 | B | 50 |
| 2026-08-04 | A | 103 |
| 2026-08-04 | B | 49 |

넓은 형식에서는 날짜가 행, 각 자산이 열이 된다.

| date | A | B |
|---|---:|---:|
| 2026-08-03 | 100 | 50 |
| 2026-08-04 | 103 | 49 |

긴 형식은 그룹별 집계와 시각화에 편리하고, 넓은 형식은 자산 간 상관계수나 행렬 계산에 편리하다.

## 코드로 구조 변환

```python
import pandas as pd

long_data = pd.DataFrame({
    "date": pd.to_datetime([
        "2026-08-03",
        "2026-08-03",
        "2026-08-04",
        "2026-08-04",
    ]),
    "asset": ["A", "B", "A", "B"],
    "price": [100, 50, 103, 49],
})

wide_data = long_data.pivot(
    index="date",
    columns="asset",
    values="price",
)

print(wide_data)
```

`pivot()`은 동일한 날짜와 자산 조합이 하나씩 존재할 때 긴 형식을 넓은 형식으로 바꾼다. 중복 거래가 있다면 먼저 집계하거나 `pivot_table()`을 사용해야 한다.

## 데이터 점검 질문

- 한 행은 무엇을 의미하는가?
- 관측 대상과 시간 단위는 무엇인가?
- 가격은 수정주가인가 원가격인가?
- 결측값은 휴장일인가 수집 실패인가?
- 금액의 통화와 단위는 무엇인가?
- 정보의 관측 시점과 실제 공개 시점이 같은가?
- 동일한 대상과 시점이 중복되어 있는가?

## 자주 하는 실수

- 일별 데이터와 월별 데이터를 단위 조정 없이 비교한다.
- 중복 행을 독립적인 표본으로 센다.
- 휴장일 결측값을 무조건 직전 가격으로 채운다.
- 패널 데이터를 단순한 횡단면 자료로 처리한다.
- 수정주가와 원가격을 혼합한다.
