# 금융 데이터 분석 개요

> [!summary] 한눈에 보기
> 금융 데이터 분석은 가격, 거래량, 재무제표, 고객 거래, 뉴스처럼 금융 의사결정과 관련된 데이터를 정리하고 패턴을 찾는 과정이다. 미래 예측만이 목적은 아니며 현황 설명, 위험 측정, 이상 탐지, 고객 분류도 중요한 문제다.

## 왜 배우는가

금융 현상은 데이터의 양이 많고 시간에 따라 빠르게 변한다. 사람의 직관만으로 모든 종목, 고객, 거래를 동시에 비교하기 어렵기 때문에 정량적인 분석 절차가 필요하다.

대표적인 질문은 다음과 같다.

- 최근 수익률과 변동성은 어느 정도인가?
- 어떤 특성이 대출 연체와 관련되는가?
- 비슷한 소비 패턴을 가진 고객을 어떻게 묶을 수 있는가?
- 뉴스의 감성이 가격 변화와 관련되는가?
- 비정상 거래를 어떻게 탐지할 수 있는가?

## 분석 문제의 네 가지 유형

1. **기술 분석:** 과거와 현재의 상태를 요약한다.
2. **진단 분석:** 변화가 발생한 원인과 관련 요인을 탐색한다.
3. **예측 분석:** 알려진 입력으로 미래 값이나 범주를 예측한다.
4. **의사결정 분석:** 위험과 비용을 고려해 행동 기준을 정한다.

상관관계가 발견되었다고 해서 원인이라고 결론 내릴 수는 없다. 예측 성능이 높더라도 거래 비용과 실제 사용 가능한 정보 시점을 고려하면 실무적 가치가 달라질 수 있다.

## 기본 분석 절차

```text
문제 정의
→ 데이터 수집
→ 데이터 시점과 단위 확인
→ 정제와 탐색
→ 기준 모델 설정
→ 모델 학습과 평가
→ 금융적 해석
→ 재현 가능한 보고
```

금융 분석에서는 특히 **데이터가 언제 공개되었는가**를 확인해야 한다. 미래에 공개될 재무정보를 과거 예측에 사용하면 [[금융 데이터 누수]]가 발생한다.

## 수익률과 위험의 기초

시점 $t-1$의 가격을 $P_{t-1}$, 시점 $t$의 가격을 $P_t$라고 하면 단순수익률은 다음과 같다.

$$
r_t=\frac{P_t-P_{t-1}}{P_{t-1}}
$$

예를 들어 가격이 $100$에서 $103$으로 변했다면 수익률은 다음과 같다.

$$
r_t=\frac{103-100}{100}=0.03=3\%
$$

여러 기간의 수익률 변동은 [[분산]]이나 표준편차로 요약할 수 있다. 수익률의 표준편차가 크다는 것은 관측 기간에 가격 변화가 상대적으로 불안정했다는 뜻이지, 손실 확률을 완전하게 설명한다는 뜻은 아니다.

## 코드로 확인

```python
import pandas as pd

prices = pd.Series(
    [100.0, 103.0, 101.0, 105.0],
    index=pd.to_datetime([
        "2026-08-03",
        "2026-08-04",
        "2026-08-05",
        "2026-08-06",
    ]),
    name="price",
)

returns = prices.pct_change().dropna()

print(returns)
print("평균 수익률:", returns.mean())
print("표본 표준편차:", returns.std(ddof=1))
```

입력은 날짜별 가상 가격이고, `pct_change()`는 직전 행과 비교한 단순수익률을 계산한다. 출력값은 실행 환경에서 확인해야 하며, 짧은 가상 표본의 평균을 일반적인 기대수익률로 해석해서는 안 된다.

## 실제 적용 예

- 주가·환율·금리 변화의 시각화
- 카드 거래의 이상 탐지
- 고객의 신용위험 분류
- 투자 포트폴리오의 위험 요약
- 기업 공시와 뉴스의 텍스트 분석

## 자주 하는 실수

- 가격과 수익률을 같은 변수처럼 해석한다.
- 시간 순서를 무시하고 데이터를 무작위로 섞는다.
- 예측 정확도만 보고 거래 비용과 위험을 무시한다.
- 미래에 공개된 정보를 과거 예측에 사용한다.
- 분석 결과를 확정적인 투자 조언으로 표현한다.

## 연습문제

가격이 $50$, $48$, $51$로 변했다. 각 기간의 단순수익률을 계산하고 두 수익률의 부호가 무엇을 의미하는지 설명하라.

## 정답과 해설

> [!check]- 정답
> 첫 수익률은 $(48-50)/50=-0.04$, 즉 $-4\%$다. 두 번째 수익률은 $(51-48)/48=0.0625$, 즉 $6.25\%$다. 첫 기간에는 가격이 하락했고 두 번째 기간에는 상승했다.
