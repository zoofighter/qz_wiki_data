# 수학 기호 모음

노트마다 기호의 의미를 다시 정의하되, 공통 표기는 이 문서를 기준으로 통일합니다.

## 기본 기호

| 기호 | 의미 | 관련 노트 |
|---|---|---|
| $x$ | 관측값 또는 스칼라 | [[스칼라]] |
| $\mathbf{x}$ | 열벡터 | [[07. 벡터]] |
| $\mathbf{X}$ | 설계행렬 또는 데이터 행렬 | [[행렬]] |
| $n$ | 표본 크기 | [[표본]] |
| $p$ | 변수 또는 특성의 수 | [[특성]] |
| $\mu$ | 모집단 평균 | [[기댓값]] |
| $\sigma^2$ | 모집단 분산 | [[분산]] |
| $\hat{\theta}$ | 모수 $\theta$의 추정량 | [[점추정]] |

## 확률 표기

| 표기 | 의미 |
|---|---|
| $P(A)$ | 사건 $A$의 확률 |
| $P(A\mid B)$ | 사건 $B$가 주어졌을 때 $A$의 조건부확률 |
| $\mathbb{E}[X]$ | 확률변수 $X$의 기댓값 |
| $\operatorname{Var}(X)$ | 확률변수 $X$의 분산 |

## 선형대수 표기

| 표기 | 의미 |
|---|---|
| $\mathbf{x}^{\mathsf{T}}$ | 벡터 또는 행렬의 전치 |
| $\mathbf{A}^{-1}$ | 정방행렬 $\mathbf{A}$의 역행렬 |
| $\lVert\mathbf{x}\rVert_2$ | 벡터의 유클리드 노름 |
| $\mathbf{I}$ | 단위행렬 |
